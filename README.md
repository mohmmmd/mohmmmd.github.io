# mohmmmd.github.io

## محرر المخططات التفاعلي
[`/floor-plan/`](https://moh-n8n.me/floor-plan/) — أداة تعمل بالكامل داخل المتصفح (لا تُرفع الصور لأي خادم):

- رفع صورة المخطط ومعايرة مقياسها ومطابقتها مع حدود الأرض.
- أعمدة مثبّتة لا تتأثر بأي تعديل، مع محاور إنشائية والمسافات بينها.
- رسم الغرف وتعديلها بالسحب أو بالأرقام مع التقاط تلقائي للأعمدة والجدران، وعرض الأطوال والمساحات لحظياً.
- تحقق واقتراحات تعديل (أعمدة داخل الغرف، تداخل، تجاوز الارتدادات، حدود دنيا إرشادية، فراغات ضيقة).
- ترتيب تلقائي يولّد بدائل تحترم الأعمدة والغرف المقفلة، وحفظ البدائل ومقارنة مساحاتها.
- تصدير صورة PNG وجدول مساحات CSV وحفظ/فتح ملف JSON.
